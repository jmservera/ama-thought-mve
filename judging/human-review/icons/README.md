## Source

Ten unmodified SVGs from `lucide-static` 1.72.0, installed from npm:
<https://www.npmjs.com/package/lucide-static/v/1.72.0>.
Upstream: <https://github.com/lucide-icons/lucide>.

The original license file includes the ISC terms and MIT notice for
Feather-derived icons. Keep it with these assets. The builder includes its
complete contents in every generated reviewer ZIP as `ICON_LICENSE.txt`.
